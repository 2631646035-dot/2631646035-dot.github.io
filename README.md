# 个人工具与代码库

这是一个不依赖框架的单页个人主页，可直接部署到 GitHub Pages。

## 先替换这些内容

打开 `index.html`，全局搜索并替换：

- `你的名字`：替换为你的姓名或昵称
- GitHub 用户名已设置为 `2631646035-dot`
- `YN` / `YL`：替换为你的姓名首字母
- “中国”“开发者 · 工具爱好者”等个人资料
- 工具列表、项目名称、说明和项目链接

## 本地预览

直接双击 `index.html` 即可预览。也可以在此目录启动任意静态文件服务器。

## 发布到 GitHub Pages

1. 在 GitHub 新建公开仓库 `2631646035-dot.github.io`。
2. 把本目录内的文件上传到仓库根目录。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. Branch 选择 `main`，目录选择 `/ (root)`，点击 **Save**。

稍等片刻后，页面会发布在：

`https://2631646035-dot.github.io/`
